# E-commerce Sales

Scripts em Python para explorar e visualizar dados de vendas de e-commerce a partir do arquivo `clean_final_data.csv`.

## Arquivos

- **`main.py`** — Exibe um menu interativo no terminal, permitindo escolher qual coluna visualizar (data do pedido, quantidade, nome do produto, preço unitário, cidade ou idade) e mostra as primeiras 20 linhas relacionadas.
- **`graphData.py`** — Lê os dados do CSV e gera um gráfico de barras com a quantidade vendida por produto.

## Requisitos

- Python 3
- pandas
- matplotlib

## Como executar

```bash
python main.py
python graphData.py
```
