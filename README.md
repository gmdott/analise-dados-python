# E-commerce Sales

Script em Python para explorar dados de vendas de e-commerce a partir do arquivo `clean_final_data.csv`.

O programa exibe um menu interativo no terminal, permitindo escolher qual coluna visualizar (data do pedido, quantidade, nome do produto, preço unitário, cidade ou idade) e mostra as primeiras 20 linhas relacionadas.

## Requisitos

- Python 3
- pandas

## Como executar

```bash
python main.py
```
